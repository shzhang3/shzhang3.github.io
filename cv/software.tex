\cventryheading{\textbf{DLRA: dynamical low-rank Boltzmann solver}}{\href{https://github.com/shzhang3/DLRA}{GitHub}}
Python implementations of full and dynamical low-rank solvers for the stiff nonlinear Boltzmann equation, with a command-line interface, numerical tests, and simulation examples.

\cventryheading{\textbf{DLR-VPFP: low-rank kinetic simulation}}{\href{https://github.com/shzhang3/DLR-VPFP}{GitHub}}
JAX implementations of first- and second-order low-rank IMEX methods for the Vlasov--Poisson--Fokker--Planck system, with a full-tensor reference solver and scripts reproducing the paper's experiments.

\cventryheading{\textbf{RVAV: structure-preserving optimization}}{\href{https://github.com/shzhang3/RVAV}{GitHub}}
PyTorch implementation of the relaxed vector auxiliary variable optimizer and its momentum variant, with an optimizer interface and reproducible optimization examples.

\cventryheading{\textbf{VPFP inverse demo: differentiable kinetic simulation}}{\href{https://github.com/shzhang3/vpfp-inverse-demo}{GitHub}}
JAX automatic differentiation and parameter estimation for a low-rank kinetic solver, with gradient checks, refined full-tensor reference data, noisy observations, and held-out-time prediction tests.
